## 全局

**配色**（`Ui/Theme.cs`）

| 用途 | 色值 | 对比度 | 说明 |
|---|---|---|---|
| 背景 | `#0d1117` | — | 近黑 |
| 面板/卡片/表格普通行 | `#161b22` | vs 背景 1.09:1 | 深灰 |
| **表格交替行** | `#1f2731` | vs 普通行 **1.15:1** | 斑马纹，扫长表时能跟上 |
| **悬停行（表格）** | `#222a34` | 介于斑马纹与选中之间 | 鼠标划过哪行一眼看到（第 111 轮加）|
| **选中** | `#262d38` | vs 交替行 1.09:1 | 比悬停行再亮一档 |
| **表格空白区** | `#161b22` | = 面板 | 空表也是可辨认的一块（第 102 轮从背景色调上来）|
| 主色（按钮、选中文字） | `#2f81f7` | on 背景 5.05:1 | 亮蓝 |
| 正文 | `#e6edf3` | on 普通行 **14.6:1** | 近白 |
| 次要文字 | `#8b949e` | on 普通行 **5.6:1** / on 悬停 4.51:1 | 中灰 |
| 分隔线 | `#444d58` | vs 面板 2.02:1 | 第 109 轮从 `#30363d`（1.42:1 几乎看不见）调亮 |
| 成功 | `#3fb950` | — | 绿 |
| 警告 | `#d29922` | — | 黄 |
| 危险 | `#f85149` | — | 红 |

> 交替行原来是 `#13181f`，与普通行只差 **3 个色阶**（对比度 1.03:1），
> 斑马纹形同虚设。提到 `#1f2731` 后是 1.15:1，能看出来了。
> 同时把悬停色从 `#21262d` 调到 `#262d38`——否则悬停在斑马纹行上看不出变化；
> 但也不能更亮，(44,52,64) 会让次要文字对比掉到 4.08（低于 AA 的 4.5）。

**字体**：界面微软雅黑 UI，等宽 Consolas（缺失时自动回退，见「关于」页）

**窗口**：
- 默认 1400×900，按屏幕工作区自动收缩（小屏不会超出）
- 最小 980×640（小屏降到 720×480）
- 记住上次的大小、位置、停留的页面

**表格（各页共用的 `DataTable`）**：
- 行高 34、表头 36、隔行斑马纹；**鼠标悬停整行高亮**，选中再亮一档
- **空表正中间显示引导文案**（第 113 轮），每页不同、都带下一步动作，
  如首页「还没有任务。点右上角「+ 新任务」创建第一个。」
- 按钮高度五档：28（次要）/ 32（工具条）/ 34（默认）/ 36（对话框底部）/ 56（发送）

**侧栏**（左侧 212px）—— **每项前面有一个 Unicode 图标**。
顶部品牌区对齐 web 版（第 114 轮）：节点图标 + 「灵枢·SpiritScout」（间隔符亮蓝）
+ 副标题「渗透测试智能体集群」，背景是顶端掺 3% 主色的渐变：
```
◍ 灵枢 · SpiritScout       ← 图标=中心圆+三向连线+端点，同 web 版 SVG
  渗透测试智能体集群
─────────
▤  任务          ◈  仪表盘
▦  用量
─────────
⚑  编队          ◎  模型
☷  项目
─────────
✦  经验          ◊  技能
⇄  MCP 接入
⚒  本地工具
─────────
✉  通知          ⚙  设置

```

图标用 Unicode 符号（系统字体自带），**不引图标资源文件**——既有一眼可辨的层次，
又不用维护一套 png/ico。13 个符号各不相同，选中时整行变蓝、文字变亮。

**状态栏**（底部）：`就绪 · F5 刷新 · Ctrl+数字 切页 · 数据在 <路径>`

**按钮**：圆角 7px，三种形态——

| 形态 | 正常 | 悬停 |

| 主按钮 | 蓝底白字 | 稍亮的蓝 |

| 危险按钮 | 深灰底 + 红字红边 | 略红的底 |

**快捷键**：`F5`/`Ctrl+R` 刷新 · `Ctrl+1..9` 切页 · `Esc` 返回

```

每个任务是一个独立的会话；数据保存在本地，不上传
                    [搜索框] [+ 新任务] [删除] [刷新]
```
