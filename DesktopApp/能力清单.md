## 十一、明确没做的

| 项 | 为什么没做 |
|---|---|
| 力导向拓扑图 | 「拓扑」标签做的是**表格**（方向 / 状态 / 结论），不是力导向图。画力导向图是另一个工程，做了也是空壳 |
| 漏洞 / 题目标签 | 没有对应的存储层（web 那边是 `blackboard` 和 `competition`，各是一套子系统）；**空壳比不做更糟**（用户点进去看到空白会以为坏了）|
| 报告 / WP 的独立标签 | **已覆盖**：会话页「导出 MD」产出的就是同一份东西，只是没做成第 7 个标签 |
| 沙箱执行 | 桌面版没有容器；`shell` 就是本机权限（已在文档与提示词中说明） |
| 流式输出 | 非流式够用，流式会让取消逻辑复杂一档 |
| MCP 的 http/sse 长连接 | 能配能测，但只能 stdio 接入 agent（http/sse 需要各自的会话管理） |
| 主题切换 | 只有深色一套；设了开关也是假的，所以设置页里没有 |

## 十二、一句话总结

**能自己动手、能查自己的知识库、能接外部工具、能从经验里学习、跨机器不崩。**

十一项能力 + 八类环境适应 + 六项可靠性，全部有实测证据。
七项明确没做的，理由写清楚了——都是「做了也是假的」或「成本远大于收益」。

唯一无法自证的是**界面好不好看**——那只能你打开看。
