# 开发流程约定

> 一是给「继续开发时」用的流程说明，不是给使用者看的。

---

## 一、测试的节奏

**写代码阶段不要频繁启动程序。**

`build/check_all.ps1` 要跑 **160 秒左右**，其中会**启动界面 13 次**（冒烟 1 轮、
布局 1 轮、裁切 1 轮、溢出 2 轮）。每改一个函数就跑一遍，时间全花在启动上了。

### 分两个阶段

**阶段一：写代码**

改完就编译，确认语法过：

```powershell
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\build.ps1')))"
```

**不启动程序，不跑界面检查。** 编译通过就往下写。

需要验证逻辑时，写独立的测试程序（`tmp*/` 下）直接调类和方法——
那不用起界面，几毫秒就出结果。

**阶段二：整体验证**

攒够一批改动（或者功能告一段落）再跑：

```powershell
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\check_all.ps1')))"
```

一次跑完**十一项**：

```
web_parity      web 功能区块 ⊆ 桌面页面，且每页非空壳
tool_parity     6 条不变量（工具/页面图标/smoke/三份 UI 检查脚本/Modes）
doc_check       文档数字与代码一致、链接可达、文件清单、按钮文案
e2e_check       141 项断言（AgentLoop 整机 + 首次运行引导）
smoke           14 页逐页打开、关键元素在位
layout_check    控件不越界、无零尺寸
clip_check      文字不被裁
overflow_check  内容不超出窗口
fit_check       文字与盒子的贴合（对话框 + 页面 + 气泡）
theme_check     深浅主题启动 + 运行时切换（侧栏主色占比 ≥85%）
session_ui_check 会话端到端（真机发一条，判会话文件）
```

### 例外：几种情况要立刻测

| 情况 | 为什么 |
|---|---|
| 改了页面注册、主题、DPI | 影响所有页面，晚测会积累更多问题 |
| 改了 `AppPaths` / 启动流程 | 起不来就什么都测不了 |
| 用户明确要看效果 | 那是验收，不是自测 |

## 三、改动前的自查清单

改任何东西之前，先确认一几条没被破坏：

1. **`build.ps1` 必须是 UTF-8 带 BOM** —— 无 BOM 时中文全乱，编译报一堆看不懂的错
2. **只写 C# 5 语法** —— 系统自带的 `csc.exe` 不支持 C# 6+：
   不能用 `$"..."`、`async Task Main`、元组、`?.`、表达式体成员、
   属性初始化器（`get; set; } = x;`）、`out var`、`_ = expr`
3. **`JavaScriptSerializer` 把数组反序列化成 `object[]`** —— 用 `Core.Json.AsList`
4. **`DataGridView` 是原生控件** —— 别想在它上面叠控件画东西（试过四种，全失败）
5. **`FlowLayoutPanel` 加子控件是 O(n²)** —— 长列表要分批加载

## 四、常用命令

```powershell
# 只编译（写代码阶段用一个）
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\build.ps1')))"

# 全量检查（攒够改动或验收前用）
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\check_all.ps1')))"

# 只查文档数字有没有过时（改了代码后很快能跑完）
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\doc_check.ps1')))"
```

### 不启动程序的那一组（8 秒跑完 44 条断言）

```powershell
# 代码层：编译警告 / async void / GDI / 圆角 / UI 一致性 / 死代码
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\static_check.ps1')))"

# 清单层：6 条不变量
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\tool_parity.ps1')))"

# 文档层：数字 / 链接 / 图片 / 文件清单 / 按钮文案
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\doc_check.ps1')))"

# 对齐层：web 区块 ⊆ 桌面页面
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\web_parity.ps1')))"

# 视觉层：截图实际像素 vs 理论混色值
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\color_check.ps1')))"
```

**一五个都不启动 `灵枢.exe`** —— 纯文本分析、源码扫描、截图取色。
写完代码想确认「清单有没有对齐」时，跑一一组就够了，不用等 160 秒。

## 五、文档同步

改完代码跑一次：

```powershell
powershell -NoProfile -Command "& ([scriptblock]::Create((Get-Content -Raw -Encoding UTF8 'build\doc_sync.ps1')))"
```

它会把「总计 N 行」「N KB」「分模块的 N 个 · M 行」「行数分布整块」
按真值改掉，免得手改漏。

**改完再跑一次 `doc_check` 确认** —— `doc_sync` 只管「能自动算的」，
剩下那些（断言数、检查项数）它管不了，只能靠 `doc_check` 报出来。

> **一两个脚本的分工**：
> - `doc_sync` —— 能算出真值的，直接改
> - `doc_check` —— 算不出来的，报「写成 X 了，应该是 Y」，人去改
